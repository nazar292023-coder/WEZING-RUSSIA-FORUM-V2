# WEZING RUSSIA Forum Bot

## В составе
- `forum_bot/main.py` — бот и кнопки меню.
- `forum_bot.sqlite3` — база создаётся автоматически при первом запуске.
- `/start`, `/id`, `/admin`.
- Разделы: заявки, организации, медиа, донат-услуги, ежедневный подарок, правила, поддержка, профиль.
- Управление набором администратора, лидеров и медиа.
- Ежедневная скидка 5–20%, забрать или отложить на 2 дня.
- Анимация подарка через Telegram GIF/file_id или прямую ссылку.

## Загрузка на Render
1. Загрузите файлы архива в корень GitHub-репозитория `WEZING-RUSSIA-FORUM`.
2. Render → New → Web Service → подключите репозиторий.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python -m forum_bot.main`
5. В Environment добавьте `BOT_TOKEN`, `ADMIN_IDS`, `GIFT_ANIMATION`.
6. Для `ADMIN_IDS` укажите свой цифровой Telegram ID. Узнать его: запустите бота и отправьте `/id`.
7. По желанию задайте `DAILY_DISCOUNT_MIN=5`, `DAILY_DISCOUNT_MAX=20`, `GIFT_ANIMATION=<file_id или URL>`.

## Важно
- Не отправляйте BOT_TOKEN в чат и не храните его в GitHub.
- Это отдельная папка `forum_bot`; если в репозитории уже есть `donate_bot/`, не удаляйте её.
- Донат-раздел пока принимает заявки на услугу и пересылает их администратору; онлайн-оплата и автоматическая выдача не подключены.
- Экзамены на 20 вопросов/5 минут и трёхдневный запрет повторной попытки ещё нужно подключить отдельным этапом.
- Для гарантированной доставки уведомления об истечении подарка Render должен быть постоянно запущен. На бесплатном тарифе при сне сервиса уведомление может задержаться.
- Текущие правила — стартовый вариант; утвердите их перед публикацией.
- Добавьте настоящие ссылки групп и настройте администратора.
